# Expert Evaluation Results

This directory contains the human expert evaluation results comparing two report generation methods:

## Methods Evaluated
1. **Template-based Method** - Traditional structured report generation
2. **MRG_LLM Method** - Large Language Model-based report generation using GPT-4

## Files Structure

### Data Files (Anonymized)
- `results-survey728958_anonymized.csv` - Survey V1 responses 
- `results-survey589241_anonymized.csv` - Survey V2 responses

### Analysis
- `eval_results.ipynb` - Jupyter notebook with complete analysis and visualization
  - Statistical comparisons between methods
  - Radar charts and box plots

### Figures
- `Fig/radar_chart.png` - Radar chart comparing methods across evaluation criteria
- `Multi-plot_comparison.jpg` - Box plot comparisons by criteria

## Participants
- **8 Expert Evaluators** (anonymized)
  - 4 Professional orthophonists
  - 4 Advanced students (4th year and final year)

## Evaluation Criteria
1. **Fluidity** - Reading flow and comprehensibility
2. **Conciseness** - Information density and brevity
3. **Relevance** - Pertinence of included information
4. **Coherence** - Logical consistency
5. **Session Info** - Quality of session description
6. **Affective States** - Description of emotional states
7. **Results** - Clarity of exercise results presentation
8. **Cognitive Functions** - Precision of cognitive assessment
9. **Linguistic Indicators** - Usefulness of language metrics

## Privacy & Ethics
- All personal information has been anonymized
- IP addresses, detailed timestamps, and identifying information removed
- Only research-relevant data preserved
- Safe for sharing and publication
